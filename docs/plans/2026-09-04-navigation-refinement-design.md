# Refinamiento de navegación y leyenda

## Decisión aprobada

Usar una sidebar editorial para las cuatro secciones del informe. La navegación muestra
numeración `01` a `04`, un indicador vertical para la sección activa y una jerarquía
tipográfica clara. Se retira la app bar superior porque duplica la función de orientación
de la sidebar.

## Leyenda semántica

Los cinco estados de dominio dejan de presentarse como pills sólidos. Cada etiqueta usa un
fondo muy claro, un borde tonal y un punto de color; así preserva el significado sin competir
visualmente con las métricas y gráficas.

## Limpieza de desarrollo

Se deshabilita el indicador de desarrollo de Next.js desde configuración. No se oculta con
CSS ni se modifica el contenido de las secciones de simulación.
